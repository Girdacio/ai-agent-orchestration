# IA

## Objetivo
Este projeto é uma implementação mínima em Python para demonstrar um hello world funcional com execução simples e teste unitário.

## Tecnologias
- Python 3
- unittest

## Estrutura do projeto
- main.py: contém a classe `Main` e o método `hello_world()`.
- test_hello_world.py: teste unitário que valida o retorno esperado.
- unit_test.py: teste de exemplo anterior do projeto.

## Serviços expostos
Este projeto não expõe endpoints HTTP REST; trata-se de um exemplo simples de aplicação Python não web.

## Dependências
- Nenhuma dependência externa declarada no projeto atual.

## Como rodar localmente
```bash
python main.py
```

Saída esperada:
```text
Hello, World!
```

## Como executar testes
```bash
python -m unittest -v test_hello_world.py
```
