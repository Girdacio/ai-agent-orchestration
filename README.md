# IA

## Objetivo
Este projeto é uma implementação mínima em Python para demonstrar um hello world funcional, com execução simples e testes unitários.

## Tecnologias
- Python 3
- unittest

## Estrutura do projeto
- main.py: contém a classe `Main` e o método `hello_world()`.
- test_hello_world.py: valida o comportamento esperado do hello world.
- unit_test.py: exemplo adicional com testes de soma.

## Serviços expostos
Este projeto não expõe endpoints HTTP REST; trata-se de um exemplo simples de aplicação Python não web.

## Dependências
- Nenhuma dependência externa declarada no projeto atual.

## Como rodar localmente
```bash
python main.py
```

Saída esperada:
```text
Hello, World!
```

## Como executar testes
```bash
python -m unittest -v
```
